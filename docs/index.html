Missões Concluídas

Projetos acadêmicos com foco em produto, interface, implementação e colaboração em equipe.

AgriRS Lab

Desenvolvimento de um website para centralizar informações do Laboratório de Sensoriamento Remoto Agrícola do INPE, ampliando a visibilidade de pesquisas, projetos e iniciativas.

Na 1º Sprint eu Atuei no design da página de notícias no Figma e implementei o front-end, utlizando ferrmantas como HTML, CSS e JavaScript para criar uma interface moderna e responsiva.

Na 2ª Sprint, atuei no desenvolvimento do CRUD para o back-end em JavaScript, viabilizando a criação, leitura, atualização e exclusão de notícias. Além disso, integrei essas funcionalidades a uma interface moderna baseada em cards.

Na terceira e última Sprint, foi a finalização do CRUD, com isto consegui estabelecer a integração completa com o banco de dados. Com isso, a página de notícias tornou-se totalmente funcional, operando com persistência de dados em tempo real.
